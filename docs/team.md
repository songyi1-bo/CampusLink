# 工作分配安排

项目按公共功能和三个业务模块分工。公共功能先完成账号、页面布局和接口基础，其他成员在此基础上实现各自模块，最后共同完成联调与提交。

| 工作内容 | 成员姓名、学号 | 主要任务 |
| --- | --- | --- |
| 公共框架 | 待填写 | 工程搭建、注册登录、个人资料、图片上传、公共页面与接口；整理文档中的公共部分 |
| 校园拼车 | 待填写 | 拼车模块的需求分析、数据库和程序设计、功能实现及测试 |
| 校园悬赏 | 待填写 | 悬赏模块的需求分析、数据库和程序设计、功能实现及测试，维护 quest-plan.md 和功能三报告 |
| 二手书 | 待填写 | 二手书模块的需求分析、数据库和程序设计、功能实现及测试 |
| 系统集成 | 组内协商兼任 | 代码合并、数据库脚本整理、联调、部署和提交材料汇总 |

各成员同时负责六类文档中与自己模块有关的内容。框架设计的个人工作说明另见 [公共框架设计与开发思路](framework.md)。

开发时使用各自的模块目录；涉及公共用户表、认证、页面布局或请求工具的修改，先在组内讨论。合并前检查主要操作流程，并记录发现的问题和处理结果。最终提交时补齐姓名、学号和实际完成情况。
