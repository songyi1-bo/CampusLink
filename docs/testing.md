## 二手书测试记录（2026-10-19）

通过 Vite 开发代理对本机真实 MySQL 执行接口级验证，覆盖发布、编辑、收藏、权限和状态机：

- 发布含 2 张图片、含原价的书籍后，折扣百分比按 `(1 - 现价/原价)` 正确计算；提交负价格、空图片列表、原价低于现价、引用不存在的上传文件、请求体含多余字段，均返回 422，公开详情接口响应不包含联系方式字段。
- 发布者查看自己书籍的联系方式返回 200（用于编辑回显）；非发布者在书籍在售或已预定时查看联系方式返回 200，书籍已售出或下架后返回 403；非发布者收藏自己不拥有的书籍成功，发布者收藏自己发布的书籍返回 403。
- 8 个并发请求对同一书籍执行收藏操作，全部返回 200 且未触发服务端异常，最终收藏计数稳定为 1，验证了依赖数据库唯一约束而非行锁处理并发收藏的正确性。
- 状态机验证：在售可编辑，标记已预定后编辑返回 409，取消预定后恢复可编辑；标记已售出后书摊默认列表不再包含该书籍，但详情页仍可通过原链接访问，且发布者仍可查看联系方式、非发布者不能。
- 关键词、分类、成色、交易方式、价格区间及排序的组合筛选返回结果符合预期交集。
- 发现并修复一处问题：联系方式接口最初禁止发布者查看自己的联系方式，导致编辑页面无法正确回显已保存的联系方式，编辑后会把联系方式静默重置为表单默认值；修正为发布者可随时查看自己书籍的联系方式后，复测确认编辑回显正确，不再丢失已保存数据。
- 前端类型检查（vue-tsc）及生产构建（vite build）通过。

本次二手书测试通过接口请求和真实数据库验证完成，尚未进行人工浏览器点击操作及 375px 手机宽度人工复查，相关结果待后续补充。开发期间创建的测试书籍和收藏记录已在验证后清除，未保留在开发数据库中。
