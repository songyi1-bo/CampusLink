# 用户手册

本手册介绍 CampusLink 的访问方式和操作步骤。涵盖账号、个人资料、校园拼车、校园悬赏和二手书操作。

## 公共入口与浏览

按项目 README 启动后，打开 http://127.0.0.1:5173。首页有校园拼车、校园悬赏、二手书三个入口，访客可直接访问。手机点击顶部“菜单”展开导航。

校园悬赏提供大厅、发布、详情和我的悬赏入口。

## 注册与登录

1. 点击“加入我们”或首页“加入 CampusLink”，输入用户名、密码和确认密码，昵称选填。
2. 用户名使用 3–32 位字母、数字或下划线；密码为 8–128 字符。用户名不区分输入大小写，保存为小写，注册后不可修改。
3. 注册成功进入登录页，用户名已填好，输入密码登录。
4. 通过受保护入口进入登录页时，登录成功会返回原页面。

开发体验可使用 `user01、user02、user03`，初始密码均为 `CampusLink123!`，需先运行开发账号初始化脚本。真实使用时可自行注册账号。

## 个人资料

点击顶部昵称或“我的 CampusLink”进入个人中心。修改昵称后点击“保存资料”，看到“资料已保存”表示成功。

点击“更换头像”选择 JPEG、PNG 或 WebP 图片，文件不超过 5 MiB。选择后自动上传并保存，无需再次点击保存资料。失败时保留原头像，可重新选择文件重试。

“我的拼车”“我的悬赏”“我的书籍”需要登录，分别查看本人发布、参与或收藏的记录。个人中心暂不提供修改用户名、修改密码、找回密码或注销账号功能。

## 退出与常见问题

- 点击“退出登录”结束当前浏览器的登录状态。
- 登录有效期为 24 小时，过期后重新登录；刷新页面通常会自动恢复有效登录状态。
- 用户名重复：换一个用户名；账号密码错误：检查后重新输入。
- 图片不合法或超限：选择格式正确、体积更小的图片。
- 网络连接失败：检查前后端是否启动；服务不可用时联系框架负责人检查数据库。

请勿在公共电脑上保留登录状态，使用完成后退出。

## 校园拼车

1. 进入“校园拼车”，按出发地、目的地、日期及剩余名额筛选同行。地点输入文字时按名称包含匹配；点击旁边“地图选点”后按附近直线距离查找，默认 3 公里，可调整到 1、5、10 或 20 公里。两端都选点时需同时满足范围。没有对应坐标的行程不会进入距离结果，可修改文字或重置恢复名称查找。
2. 登录后点击“发布拼车”，填写三个地点、北京时间、招募人数及联系方式。费用可以留空。地图选点可搜索地点、点击地图或主动定位；地图不可用时手动填写地点名称。
3. 在详情点击“加入拼车”，留下提供给发起人的联系方式；加入成功后可查看发起人的联系方式。
4. 出发前可退出，退出后释放名额且不再显示联系方式。发起人可在无人加入时编辑、出发前取消、出发后标记完成。
5. 在“我的拼车”切换我发布的和我参与的查看记录。取消、完成及退出记录仍保留。地图地点和集合说明公开展示，联系方式按参与权限展示。

## 校园悬赏

1. 打开校园悬赏，按关键词、分类和状态筛选，选择最新发布、赏金从高到低或即将截止排序。默认仅展示可接单任务。
2. 登录后点击发布悬赏，填写标题、分类、描述、地点、赏金、未来 30 天内的截止时间和联系方式。联系方式不要写进公开描述。
3. 打开详情点击我要接单，填写联系方式并确认。每条任务只有一个接单名额；发布者不能接取自己的任务。接单后双方可点击查看联系方式进行线下沟通。
4. 接单者在提交前可以撤回，之后不再拥有联系权限；过期任务撤回后不会重新开放接单。
5. 完成任务后点击提交完成并填写完成说明；发布者核实后点击确认完成。赏金由双方在线下结算。
6. 我的悬赏包含我发布的和我接取的，可按状态查询。发布者可编辑未过期且无人接单的悬赏，也可取消无人接单的悬赏；已完成与已取消记录继续保留。撤回任务不再列入我接取的。

## 二手书

1. 进入“校园二手书”，可按书名/作者关键词、分类、成色、交易方式、价格区间筛选，也可勾选“可议价”“仅看在售”，并选择按最新发布或价格排序查找书籍。
2. 登录后点击“发布书籍”，填写书名、作者、ISBN（选填）、分类、成色、描述、上传 1–6 张图片（第一张为封面）、现价、可选原价、是否可议价、交易方式和交易地点，再填写联系方式。
3. 在详情页可以收藏感兴趣的书籍，也可以点击“查看联系方式”联系卖家进一步沟通和验货。书籍已售出或下架后，联系方式不再对外开放。
4. 在“我的书籍”切换“我发布的”和“我收藏的”查看记录。发布者可以编辑仍在售的书籍、标记已预定、取消预定、标记已售出或下架；已预定、已售出和已下架的书籍不能再编辑详情，下架和售出记录仍保留在“我发布的”中。
